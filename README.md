# Transparent Prism Collection — Pop OS Cosmic

A collection of translucent dark themes for the **Pop OS Cosmic** desktop, designed to complement Cosmic's native blur and transparency effects. Based on Zedokai Darker (Filter Spectrum) — ported from the original [dark-glass-theme](https://github.com/magnuspladsen/dark-glass-theme#transparent-dark-glass-theme) by [MagnusPladsen](https://github.com/MagnusPladsen).

## Features

- Blurred translucent backgrounds for a modern glass-like appearance
- Tuned specifically for Pop OS Cosmic's design language
- Based on the popular Zedokai Darker (Filter Spectrum) color scheme
- Carefully tuned transparency levels for optimal readability
- Custom styling for editor, panels, terminal, and UI elements
- 16 colour variants to match any mood or wallpaper

## Installation

1. Clone this repository
   ```bash
   git clone https://github.com/your-username/transparent-prism-cosmic.git
   ```
2. Open **COSMIC Settings**
3. Navigate to **Desktop → Appearance**
4. Click **Import** and browse to the cloned directory
5. Select your desired `.ron` theme file
6. The theme applies instantly

## Pop OS Cosmic Tips

For the best glass effect on Cosmic, make sure you have:

- **Compositor effects enabled** — Settings → Desktop → Enable animations & transparency
- **A blurred wallpaper** — enhances the translucency effect noticeably
- Windows in **floating mode** for maximum visual impact
